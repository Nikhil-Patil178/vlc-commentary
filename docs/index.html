How it works

  1. Open a film in VLC.
  2. Press Ctrl+Alt+N. A note box appears with the current time, e.g. 00:12:10.
  3. Write what you see, think or feel. Tap Tab to mark it as an Observation, Interpretation, Emotion or Question.
  4. Press Enter. The note is saved and the box disappears. Hold Tab any time to see your earlier notes.

Every film gets its own folder with your notes and its subtitles:

Documents\VLC Commentary\Taare Zameen Par\
  Taare Zameen Par.md       ## [00:12:10] Emotion
                            His father's voice makes me tense; the score drops out.
  Taare Zameen Par.json
  Taare Zameen Par.eng.srt  the film's subtitles, so you can quote dialogue

Questions

Is this a VLC plugin?

It works like one. VLC's own extensions can't draw a note box over the video or listen for a hotkey, so VLC Commentary is a small companion app that talks to VLC through VLC's built-in web interface, which is limited to your own PC and password-protected. The installer sets it all up.

Do I need to install anything else?

No. The installer adds VLC if it's missing and FFmpeg for subtitles. No admin rights are needed except to install VLC.

Windows says "unknown publisher". Is it safe?

The installer isn't code-signed yet, so SmartScreen shows a warning. Click More info → Run anyway. The full source code is on GitHub.

Mac or Linux?

Not yet. Windows 10 and 11 only for now.

Can I use the notes in my essay?

Yes. They're Markdown files, which you can paste into Word, Google Docs, Notion or Obsidian. Export to SRT, so your commentary plays as subtitles, is planned.
