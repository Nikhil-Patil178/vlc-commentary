If the phone can't connect

  • Windows Firewall: when Windows asked whether to allow VLC Commentary, it needed Private networks ticked. To fix it later: Start → Allow an app through Windows Firewall → Change settings → tick Private for VLC Commentary.
  • Network set to Public: Settings → Network & internet → Wi-Fi → your network → set Network profile type to Private.
  • Guest Wi-Fi or "AP isolation" on the router stops devices seeing each other. Use the main network.
  • Keep this link private: anyone with it, on your Wi-Fi, can add notes and control playback.
